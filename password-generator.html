What makes a password strong?

  • Length above all — each extra character multiplies the number of possible passwords.
  • Mix of character types — letters, numbers and symbols.
  • No personal info — birthdays and names are the first things attackers try.
  • Never reuse passwords — a password manager makes this easy.

Password generator FAQs

Can I choose the password length?

Yes. Use the length slider to choose from 8 to 64 characters and select which character groups to include.

Is the generated password sent anywhere?

No. Password generation runs in your browser. Copy it somewhere secure, such as a trusted password manager.
